# Choose another match after quality review

## Problem and decision

A measured lossless refusal is durable, but Missing Music currently sends the
recipient toward advanced diagnostics to choose a replacement. Reuse the existing
bounded match chooser and explicit selection command inside the release inspector.
Show a native disclosure only when current, eligible alternatives exist.

Selection records a replacement; it does not start a transfer, retry the failed
download, change quality consent, erase evidence or create an apply run.

## Ownership and implementation

The server resolves the recipient from the authenticated actor and wanted release.
A small import-candidate service owns alternative eligibility and the short write
transaction. Reuse current safe-add scope, account and discovery locks, shared
participant policy resolution, track-scope verification, and candidate selection.
Re-read after acquiring locks. Deny stale searches, changed recipients, disabled or
fulfilled participants, conflicting work and weaker candidate quality contexts.
Advertised lossless may be downloaded for inspection; actual measured verification
remains mandatory before library add. Never copy fallback consent to a replacement.

Candidate transition, selection event and required audit commit together. Advisory
Activity follows commit. The failed candidate and downloaded bytes remain intact.
The public projection includes only existing bounded file/format/size facts.

## Acceptance

Focused policy and presentation checks precede real PostgreSQL/HTTP coverage for
shared scope, lower quality, stale state, account changes, concurrent selection,
idempotency and publication rollback. Browser checks use the real app and API for
keyboard disclosure, retained focus, selection feedback and explicit no-download.
Run the stable fast gate once, affected integration/browser lanes, then preserve
the existing local installation during the no-cache walkthrough rebuild.

Screen-reader and physical-device acceptance remain manual work. Browser semantics
alone do not establish WCAG conformance.
