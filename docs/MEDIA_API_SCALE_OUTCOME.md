## Final recommendation stack

Keep current defaults and the owned hybrid pilot explicit. Pair bounded pure
policy tests with the selected canonical workload and this targeted native
socket lane; keep the full matrix an intentional separate collection. The
benefit is useful scale/platform evidence without making every fast run slower.
The tradeoffs are one-host coverage, explicit privileged test access and extra
fixture lifetime code that must preserve uncertain-workspace retention.
