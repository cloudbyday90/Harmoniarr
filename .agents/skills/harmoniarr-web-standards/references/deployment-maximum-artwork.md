# Maximum artwork and bounded native outcomes

Use for fixed maximum-resolution JPEG/WebP resource qualification. Read active-repo
docs/DEPLOYMENT_MAXIMUM_ARTWORK_DESIGN.md, research/outcome and
[mixed workload ownership](deployment-review-memory.md).

The current fixed maximum entry requires deliberate pre-grant memory refusal;
read [rewrite headroom](artwork-rewrite-headroom.md). Historical native-abort
containment remains diagnostic evidence and cannot pass that repaired regression.

- Use the fixed maximum selectors before pool acquisition. TIFF is a supported
  generation source; lazy sixteen-row strips avoid a full raw JavaScript image.
  Check actual decode/pixel parity with a tiny multi-strip file before native work.
  Fixture encoder settings and deadlines are separate from production policy.
- Retire the owned raw source and restore Sharp preferences before application
  work. Stream thresholds do not bound libvips/WebP native memory. Include setup,
  generation and cleanup in lifetime kernel counters/peaks.
- Preserve real transport, admission and native children. Large encoded jobs can
  exceed queue-byte allowance: require an owned capacity error and account exactly
  for the missing child. At least one actual decoder must exercise the input.
- Keep successful publication and graceful refusal separate from SIGABRT plus
  owned worker-failed containment. Report the latter explicitly; it does not
  prove correct decoding or identify an allocation failure. Reject unexpected
  signals, cancellation, forged errors and kernel limit/OOM events. Preserve the
  older corpus's strict success/memory-refusal expectations.
- Require no orphan asset/file/assignment, actual close/process absence, zero
  reservation, released leases and successful review/media work. A containment
  pass cannot be described as maximum-image feature support.
- Run fresh two-format × two-cap native profiles outside the fast gate, plus the
  affected default and representative strict corpus regressions. Preserve failure
  candidates, freeze source through final proof and retain unrelated evidence
  only after exact comparison. Do not raise limits to obtain a passing fixture.
