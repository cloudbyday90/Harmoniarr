# Search again after measured refusal

Use for restarting discovery after current measured quality review. Read the
active repository's docs/QUALITY_REVIEW_SEARCH_DESIGN.md, research and outcome.

1. Trace the native command through scoped detail, fresh-session/CSRF route,
   acquisition adapter, guarded library intent, dispatcher and ingestion. Reuse
   existing queue, idempotency, feedback and focus owners.
2. Establish exhaustion across the whole current search in bounded keyset pages.
   An empty twelve-choice public shortlist is not proof that no alternative exists.
   Follow [bounded qualification](bounded-restart-qualification.md) for current
   durable steps and atomic current revision fencing instead of full traversal.
3. Share the current quality-review scope with replacement selection. Lock current
   maintenance/accounts/wanted/discovery/creation/candidate owners; read after lock
   waits and recheck actor role, participant identity, missing state and track scope.
4. Commit root intent, target marker and required audit together. Distinguish one
   shared restart from each recipient's own coalesced intent. Keep failed candidate
   evidence and bytes intact. Dispatch follows durable acceptance.
5. Store the original quality floor and recipient identity without copying consent.
   Merge it with stricter current policy before query construction and ingestion.
   Ordinary later retries retain the floor; explicit quality fallback has its own
   authority. Check numeric floors as well as advertised formats.
6. Refuse malformed or changed queued scope before provider work. Preserve refusal
   through reconciliation and condition terminal writes on the captured claim so
   stale work cannot stop a replacement search.
7. Apply W3C status guidance to queued feedback and OWASP action authorization to
   the actual write boundary. Keep background focus quiet; describe accepted intent
   without promising completed discovery, downloads or library add.
8. Prove beyond-shortlist and beyond-page alternatives, rollback, replay/coalescing,
   real lock waits, actual SQL claim and query/ingestion arguments, post-queue drift,
   stale terminal-write refusal, keyboard activation, refreshed state and reload.
   Controlled provider calls do not establish public discovery or measured audio.

Use official MCP-discovered sources and distinguish informative guidance from
normative requirements. Freeze source before the stable fast gate and compare
exact packaged runtime bytes before retaining unrelated native qualifications.
