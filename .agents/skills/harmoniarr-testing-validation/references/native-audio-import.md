# Native audio through canonical import

Use validate:native-slskd-audio for changes to this native media/import boundary.
Read docs/NATIVE_AUDIO_IMPORT_DESIGN.md and its outcome; keep routine byte and
capability controls in the fast lane. This opt-in case owns fresh PostgreSQL,
an internal-network provider and an isolated network-disabled media reader.

- Declare bounded valid audio and an equal-size corrupt control. Both must
  complete actual provider transfer before content acceptance is compared.
- The audio lane now starts from metadata and durable monitoring. Actual wanted/
  discovery reconciliation, authenticated Find matches, queue/worker and real
  client/ingestion create candidates. No candidate or discovery result is seeded.
  Two equal sources exercise actual manual selection policy. Verify initial-intent
  audit, actor/target, same-key replay, distinct-key repeated intent, coalescing and
  refused scope/CSRF/disabled/forged-target commands before search transport.
  See docs/NATIVE_DISCOVERY_COMMAND_OUTCOME.md. Exercise actual authenticated
  Missing Music selection/start, real planner, queued execution and worker.
  Prove same-key replay, different-key active-work refusal, actor/recipient and
  CSRF/disabled/own-scope refusals before any provider work. Refresh the actual
  decision and bounded Downloader handoff. See docs/NATIVE_CANONICAL_COMMAND_OUTCOME.md.
- Inject the real transfer snapshot owner as well as the provider service.
  Preserve current-binding checks and await durable beforeSend before POST.
  Native search now replaces owned HTTP responses: the actual provider emits
  global queries and accepts compressed peer responses with original tokens.
  Preserve zero-token and same-port login replay, refuse changed endpoints and
  token/query reuse, and distinguish socket write from native API acceptance.
  Await actual search completion before provider shutdown. See
  docs/NATIVE_SEARCH_OUTCOME.md. This is isolated owned search, not public-network
  discovery, directory browsing or browser command submission.
- Capture actual completed receipt observations before stopping the provider.
  Await task retirement, acknowledge shutdown, then inspect exact read-only
  native files. Export only fixed manifest paths into an exclusive workspace;
  refuse preexisting entries, redirected parents, nonregular/multilink files,
  oversized files and hash drift. Native and exported filesystem identities differ.
- Run actual media inspection, reconciliation, apply worker, required system
  audit and scheduled catalogue worker. Configure every real shared path,
  including transcodeTemp; never substitute a healthy readiness result.
- Require valid target hash and observed catalogue row, plus corrupt source
  retention, no apply operation, absent target and absent catalogue entry.
  Resolve actual filesystem paths for catalogue identity on Windows.
- Drain actual worker/process/socket/database/container owners on failure too.
  Retain failed prototypes separately. Metadata probing does not prove full
  decoding or authenticate a same-size changed but valid remote source.

For command Activity, trace producer through service allowlist, database CHECK,
feed projection and rendered link policy. A mocked callback does not prove event
admission. Observe/await the actual optional recording result in the parent test;
assert queued event and required audit separately, without changing production
best-effort semantics. Verify snapshot/migration anchors, unknown-type refusal
and browser visibility/focus/filtering. Explicit queued preparation stays visible
between automatic milestones and must not imply provider acceptance.

For search publication timing, use fast injected ordering and cancellation
controls before repeating native audio. Cover completion at the observation
budget boundary, late bodies, finalized zero, persistent unavailability and
original read failures. Assert no candidate transaction on unavailable/cancelled
evidence and no successful no-match cooldown/exhaustion. The existing native
audio lane verifies actual ordinary provider ingestion/publication; it does not
force the released provider's internal finalization race. Keep those claims
separate. See docs/SLSKD_SEARCH_PUBLICATION_DESIGN.md.
